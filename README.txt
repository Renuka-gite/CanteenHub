CanteenHub Prototype
====================

Experiment 5 - Prototype Development

How to run:
1. Extract this ZIP.
2. Open the CanteenHub_Prototype folder in VS Code.
3. Open index.html in a browser, OR right-click index.html and choose "Open with Live Server".
4. No backend, database, npm install, or internet connection is required.

Prototype flow:
Login -> Home/Menu -> Filters/Recommendations -> Cart -> Checkout
-> Pickup Time -> Payment -> Order Confirmation -> Order Tracking
-> Ready -> I'm Here -> OTP (for Pay Now) -> Completed

Files:
- index.html
- style.css
- script.js

This is a front-end Proof of Concept intended for user-flow demonstration and usability testing.

Menu images:
- Each menu item is defined in script.js with an image: "" field.
- Paste the image URL between the quotes. The menu will display the image automatically.
- Until a URL is added, the card shows a clean image placeholder.
